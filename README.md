# Amazon Review Sentiment Analysis

## Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning to predict ratings from Amazon product reviews.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- TF-IDF Vectorization
- Streamlit

## Features
- Enter an Amazon product review.
- Predict the review rating using a trained machine learning model.
- View the prediction through a Streamlit web application.

## How to Run
1. Install the required packages:
   `pip install -r requirements.txt`
2. Ensure the trained model and TF-IDF vectorizer files are available in the project folder.
3. Run the application:
   `streamlit run app.py`

## Project Type
Machine Learning | Natural Language Processing | Text Analytics
